# Hành trình Vẹt Vectơ · Toán 10

Game ôn tập Toán 10 giữa học kì I (Chương I–IV): 8 địa danh trên bản đồ Việt Nam, 4 mức độ mỗi bài, Phiếu điểm 10 đặc sản, sổ tay công thức, hộp quẻ học tập và nhạc nền.

Toàn bộ game nằm trong một tệp `index.html`, không cần cài đặt hay build. Tiến độ của học sinh lưu trong trình duyệt (localStorage); muốn chuyển máy thì dùng mã sao lưu trong phần Cài đặt.

## Triển khai lên Vercel
1. Đưa thư mục này lên một repo GitHub tên `vetvector`.
2. Vào vercel.com → Add New → Project → Import repo `vetvector`.
3. Framework Preset: **Other**. Build Command và Output Directory để trống. Bấm Deploy.
4. Trang chạy ở `https://vetvector.vercel.app` (nếu tên còn trống). Có thể đổi trong Settings → Domains.
